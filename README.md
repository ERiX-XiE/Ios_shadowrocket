# Shadowrocket configuration

Public Shadowrocket routing configuration for personal use.

## Download URL

`https://raw.githubusercontent.com/ERiX-XiE/Ios_shadowrocket/main/erix20261016_chatgpt_US01.conf`

Import in Shadowrocket via **Config → + → Download**, then select **Use Config**. Enable **Global Routing → Config** to use the domain rules. Update the remote configuration from its Config menu after subsequent GitHub changes; optional automatic configuration updates depend on iOS background refresh.

## Configuration

- `erix20261016_chatgpt_US01.conf`: uploaded configuration; original routing preserved.
- `ChatGPT-US` is a legacy group name. Its selected node is `🇨🇳 台湾 02`, which should remain selected unless explicitly requested otherwise.
- The proxy nodes are expected to be maintained separately within Shadowrocket.
- Do not add passwords, tokens, or private proxy subscription URLs to this public repository.
- Keep a local or iCloud copy of the last known-good configuration before changing rules.
